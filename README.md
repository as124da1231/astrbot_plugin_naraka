# 永劫无间战绩查询

适用于 AstrBot 4.10.4 及以上版本与 QQ（aiocqhttp）的永劫无间**端游**战绩插件。按昵称或角色 ID 查询小黑盒中的近期对局、单局详情和赛季总览。数据来自小黑盒的非公开接口，使用前需由管理员扫码登录小黑盒。

项目地址：[as124da1231/astrbot_plugin_naraka](https://github.com/as124da1231/astrbot_plugin_naraka)。

## 安装与登录

将插件目录 `astrbot_plugin_naraka` 放入 AstrBot 的 `data/plugins/`，或在插件管理页上传发布 ZIP 后重载。安装 `requirements.txt` 中的依赖。管理员私聊机器人发送 `/永劫登录`，用小黑盒 App 扫码确认。登录凭证只保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_naraka/login.json`，不会打包进插件。

如果曾安装旧版 `astrbot_plugin_naraka_xhh` 或其他同名永劫插件，先停用旧插件以避免指令冲突；由于数据目录改名，新版需重新扫码登录。

## 指令

`战绩查询`、`详细查询` 和 `永劫战绩` 可以不加斜杠；加 `/` 也能使用。

| 指令 | 功能 |
| --- | --- |
| `战绩查询 <昵称或角色ID> [模式]` | 当前赛季排位、天人分数，近期有效对局数、常用英雄和场均伤害、振刀、击败 |
| `详细查询 <昵称或角色ID> [模式]` | 有效对局逐场列出英雄、击杀、伤害、恢复、振刀、存活 |
| `永劫战绩 <昵称或角色ID> [模式]` | `战绩查询` 的同义指令 |
| `/永劫搜索 <昵称>` | 搜索玩家并列出角色 ID |
| `/永劫赛季 <昵称或角色ID> [模式] [当前/全部/赛季名]` | 单独查看某模式的赛季总览 |
| `/永劫登录`、`/永劫退出` | 管理员登录或清除本地登录凭证 |

模式可以写“天选单排/双排/三排”“天人单排/双排/三排”；也可明确指定快速单排或快速三排。不指定模式时，插件先读取按时间排序的混合对局，排除快速等非排位模式，再按最新一场排位对局选择模式。快速模式没有赛季分数。

战绩概览的分数按单排、双排、三排排列为两行：

```text
排位：— 4,528 6,319
天人：— — 4,934
```

“排位”即天选之人；没有分数显示 `—`。英雄名称优先采用配置页的“英雄编号与名称对照”，其次采用小黑盒实时返回的中文目录，最后使用插件内置的编号表。数字编号仍未识别时直接显示末两位，这场对局仍计入有效对局和场均数据。完全缺少数字编号时显示“未知英雄”。

“英雄编号与名称对照”采用可展开的条目。现有编号已预填；点击“添加条目”可增加英雄，展开条目可分别修改“英雄编号”和“英雄名称”。推荐填写两位编号，例如 `30` 对应“万钧”、`70` 对应“南宫锦”、`73` 对应“叶修”；也支持填写完整编号，如 `1000030`。保存配置后，战绩概览和逐场详情都会使用修改后的名称。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 查询对局数 | 30 | 读取最近的混合对局；插件不设最大值，上游可能限制可翻页数量 |
| 有效对局选择数 | 10 | 筛出目标模式后，最多尝试查询几场单局详情 |
| 英雄编号与名称对照 | 已有 30 条 | 可添加、展开修改条目；配置名称优先于接口名称 |
| 查询间隔 | 4 秒 | 所有小黑盒战绩请求之间的最短间隔，建议 4 秒 |
| 有效对局详情查询间隔 | 4 秒 | 两次单局详情请求之间的最短间隔，建议 4 秒；同时受查询间隔约束 |
| 启用群聊白名单 | 关闭 | 开启后只允许名单内 QQ 群查询；私聊不受影响 |
| 开始查询时发送提示 | 关闭 | 开启后按下方提示方式处理发起消息 |
| 开始提示方式 | 引用 | 引用原消息发文字、@ 查询人发文字，或给原消息贴 QQ 表情回应 |
| 开始提示文字 | 正在查询战绩，请稍候… | 引用或 @ 提示的文字 |
| QQ 表情回应 ID | 277 | 选择表情回应时使用；仅 aiocqhttp 生效，失败不阻断查询 |
| 战绩结果回复方式 | @ 查询人 | 可改为引用原消息；长详情拆成多条时每条使用同一回复方式 |

小黑盒实测返回的是按时间排序的混合模式对局，插件在本地筛选。超过单页时会尝试后续页面；如果上游重复返回同一页，则停止并显示实际取得的场次。成功的单局详情会在插件运行期间缓存。登录失效或被限流时会停止后续请求。
